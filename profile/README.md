## About

Vivimentis is an independent studio focused on building enjoyable games and practical software.

We believe great products should be simple, useful, and rewarding to use. Our work combines thoughtful design, approachable experiences, and long-term craftsmanship.

---

## Current Project

### LogicForge Match

A puzzle game focused on strategy, memory, and meaningful progression.

Currently in development, LogicForge Match explores how simple mechanics can create engaging and rewarding gameplay experiences.

## Future Directions

In addition to games, Vivimentis is interested in creating:

* Learning and memory applications
* Lightweight digital utilities

Our goal is to build products that help people think, learn, create, and play.
